# Pushing to GitHub (private)

    cd ~/Documents/AI_Role_Search/Theroux/theroux-engine

    git init
    git add -A
    git commit -m "Theroux engine: constrained-disclosure measurement on 472 Fed speeches"

Create the repo (private) with the GitHub CLI:

    gh repo create theroux-engine --private --source=. --remote=origin --push

If you do not have `gh`, create an empty private repo named `theroux-engine` at
github.com/new, then:

    git remote add origin https://github.com/<your-username>/theroux-engine.git
    git branch -M main
    git push -u origin main

## Adding Palantir as reviewers

Settings → Collaborators → Add people. Add whichever GitHub handles the fellowship
gives you. Do this BEFORE submitting — a private repo a reviewer cannot open reads
as no repo at all.

**If they do not supply handles, make it public instead.** The code is defensible
and an unreadable link is worse than an open one:

    gh repo edit --visibility public --accept-visibility-change-consequences

## What gets committed

- Full source, tests, and the 472-speech Fed corpus (US Government works, public domain)
- The built `dashboard/theroux.html` — a reviewer can clone and open it with no install
- NOT `runtime.json` or `results.json`; both are regenerated by `python3 run.py`
